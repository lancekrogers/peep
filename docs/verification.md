# Bootstrap verification

Verified locally on 2026-11-21 (America/Denver), macOS arm64.

Environment: Go 1.27.3 running a Go 1.24 module; Bubble Tea 1.3.10; FFmpeg 9.0.2; mpv 0.42.0; just 1.59.0. No media binaries are bundled.

## Results

| Check | Result |
|---|---|
| `just check` | Passed formatting, `go vet`, race-enabled unit tests, and build |
| `just test-integration` | Passed real FFprobe/FFmpeg decoding and mpv load/play/pause/seek/reset/error/cleanup tests |
| `just test-tui` | Passed real PTY sessions for video, image, GIF, audio, corrupt media, filtering, and mixed queues |
| `just build-all` | Compiled macOS/Linux arm64/amd64 with CGO disabled; Linux binaries not executed |
| `just doctor` | Found ffmpeg, ffprobe, and mpv |

Synthetic fixtures: 160 x 96 PNG; three-second animated GIF; eight-second MPEG-4/AAC MP4 with a sine tone; eight-second PCM WAV with title/artist tags; corrupt PNG. Fixtures are generated by `scripts/fixtures.sh`; no personal media is used.

The PTY harness sets `TERM=xterm-256color` and `COLORTERM=truecolor`, starts at 110 x 30, and exercises 70 x 20 resizing. It confirms color-cell output, advancing media time, paused seeking in both directions, stop/reset/resume, help, silent browsing during audio playback, filtering, image → GIF → video queue advancement, paused next-item navigation, and error visibility. It checks alternate-screen exit, restored terminal attributes (normalizing macOS's kernel-managed PENDIN flag), and disappearance of child processes. Raw transcripts are generated under `tmp/acceptance/` and intentionally ignored by git.

## Limits of the evidence

The harness is a real pseudo-terminal, not a named graphical terminal emulator. It verifies terminal I/O and state transitions, not how every emulator displays the cells. mpv tests use its null audio output; speaker output and perceptual audio/video synchronization were not audited. The renderer targets 12 fps, but no sustained frame-rate or CPU benchmark is claimed. Kitty graphics, tmux, SSH audio forwarding, Windows, subtitles, and a codec matrix beyond the listed fixtures remain unverified or unimplemented.

The bootstrap proof established that separate frame decoding can coexist with live TUI controls, seeking, resizing, and clean shutdown. Native-resolution graphics and a more efficient shared decoder are follow-up implementation work, not claims of this version.
